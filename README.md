
# BhashaLab-AI

An experimental speech engineering and evaluation
platform for Hindi, English and Gujarati.

## Initial Objectives

- Audio inspection and preprocessing
- Automatic Speech Recognition evaluation
- Whisper vs Sarvam Saaras comparison
- WER and CER measurement
- Latency, reliability and cost analysis
- Language identification and text-to-speech

## Current Stage

Day 1: Repository and development environment setup.

## Technology Stack

- Python
- Librosa
- NumPy
- SciPy
- SoundFile
- Matplotlib
- Pandas
- Pytest
